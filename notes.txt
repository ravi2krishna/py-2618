    -> Looping Structures (Iteration Statements) - Repetition

        -> Loops in Python are used to "repeatedly" execute a block of code 
        until a specific condition is met or for each item in a sequence.

        -> Repeatedly execute a block of code until a specific condition is met

            -> Every Month Last 3 Days Send SMS / Email to customer about EMI till Loan is Repaid  

        -> Repeatedly execute a block of code for each item in a sequence

            -> Products Catalog With 15k Products (Ecommerce Platform)

        -> NOTE: When you want to do a task multiple times, use loops 

        -> while loop 

            -> while loops execute a block of code repeatedly 
            as long as a specified condition remains True

            -> Syntax 

                while condition:
                    block of code 

            
            -> NOTE: We use while loop, when we don't know number of
            Iterations/Repetitions in advance


        -> for loop 

            -> for loop is used to "iterate over a sequence" 
            (like a list, tuple, string, or range) 

            -> NOTE: For loop executes a block of code once, for each item in the sequence. 

            -> Syntax 

                for variable_name in sequence:
                    block of code 

            -> NOTE: We use for loop, when we know number of
            Iterations/Repetitions in advance

        
        -> range() function

            -> The range() function in Python generates a sequence of numbers. 
            It is commonly used for iterating a specific number of times in for loops.

            range(start, stop, step)
                -> start default is 0 (included) (inclusive)
                -> stop at this value (excluded) (exclusive)
                -> step is increment (default step is 1)

    
        -> Nested Loops 

            -> Loops Inside Loops 
            
            -> A nested loop in Python is a "loop placed inside the body of another loop". 
            This structure is used to handle multidimensional data (like grids or lists within lists), 
            generate patterns, and perform actions that require "multiple layers of iteration".


    -> Branching Structures (Jump Statements)

        -> Used within loops, these statements also control the flow of execution

            -> allowing you to exit a loop early (break) 
            
            -> skip the current iteration (continue)

                -> break: Helps exit a loop early (break)  

                -> continue: Helps Skip The Current Iteration

                -> pass: Acts a place holder

        -> Accessing Strings 

            -> Indexing 

                -> String indexing in Python allows access to 
                "individual characters within a string" 
                using their "position", known as the "index".

                -> Python uses zero-based indexing, meaning the first character is at index 0, 
                the second at index 1, and so on.

                -> Syntax 

                    print(string[index])

                -> Positive Indexing

                    Starts from the beginning of the string.
                    The index of the first character is 0.


                -> Negative Indexing

                    Starts from the end of the string.
                    The index of the last character is -1.
                

                0   1 2  3  4  5
                p   y t  h  o  n
                -6 -5 -4 -3 -2 -1  

                -> NOTE: If Index Is Out Of Range, We Get IndexError   


            -> Slicing 

                -> String slicing in Python is a method for "extracting a portion" 
                (substring) from a larger string.

                -> It utilizes the slice operator [] with specific 
                indices to define the desired segment.

                -> Syntax 

                    string[start:end:step]

                        -> start default is 0 (included) (inclusive)
                        -> stop at this value (excluded) (exclusive)
                        -> step is increment (default step is 1)

                
            -> Earlier We Used range()
                
                range(start, stop, step)
                -> start default is 0 (included) (inclusive)
                -> stop at this value (excluded) (exclusive)
                -> step is increment (default step is 1)

    -> Dictionaries 

        -> Dictionary is a data structure which allows you to store multiple "key values"
        in a single variable, each value is separated with ,

        -> Dictionaries are represented using {} or using "dict" class  

        -> Dictionaries Store "key values" Pairs 

            -> key:value 
            
            -> {key1:value1,key2:value2,key3:value3}

            -> https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQSib6nLERnnqTxvDUQa5l1ykY9tHPi8c9mWOQV2nwnRl0vXzj01vhWtr-o&s=10


        -> Accessing Data In Dictionaries 

            -> NOTE: Like In Strings, We Don't Have index Concept In Dictionaries

                -> Dictionaries Doesn't Have Index 

                -> NO SUPPORT FOR Both Positive and Negative Index 

                -> NO SUPPORT FOR Slicing 

            -> Loops We Can Apply 

            -> Operators We Can Apply 

            -> Conditionals We Can Apply 

            -> Duplicates Allowed (*)

                -> Values Can Be Duplicated 

                -> Keys Should Be Unique 

                    -> If We Add Duplicate Key, Latest Will Override Old Key 

                    -> NOTE: Keys Must Be Immutable Objects Only, Whereas Values Can Be Any Object 

                    -> NOTE: Mostly Keys Will Be Strings 

            -> Insertion Order Is Preserved  

            -> NOTE: Dictionaries Are Mutable In Nature (Can Be Changed)
