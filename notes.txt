    -> Looping Structures (Iteration Statements) - Repetition

        -> Loops in Python are used to "repeatedly" execute a block of code 
        until a specific condition is met or for each item in a sequence.

        -> Repeatedly execute a block of code until a specific condition is met

            -> Every Month Last 3 Days Send SMS / Email to customer about EMI till Loan is Repaid  

        -> Repeatedly execute a block of code for each item in a sequence

            -> Products Catalog With 15k Products (Ecommerce Platform)

        -> NOTE: When you want to do a task multiple times, use loops 

        -> while loop 

            -> while loops execute a block of code repeatedly 
            as long as a specified condition remains True

            -> Syntax 

                while condition:
                    block of code 

            
            -> NOTE: We use while loop, when we don't know number of
            Iterations/Repetitions in advance


        -> for loop 

            -> for loop is used to "iterate over a sequence" 
            (like a list, tuple, string, or range) 

            -> NOTE: For loop executes a block of code once, for each item in the sequence. 

            -> Syntax 

                for variable_name in sequence:
                    block of code 

            -> NOTE: We use for loop, when we know number of
            Iterations/Repetitions in advance

        
        -> range() function

            -> The range() function in Python generates a sequence of numbers. 
            It is commonly used for iterating a specific number of times in for loops.

            range(start, stop, step)
                -> start default is 0 (included) (inclusive)
                -> stop at this value (excluded) (exclusive)
                -> step is increment (default step is 1)

    
        -> Nested Loops 

            -> Loops Inside Loops 
            
            -> A nested loop in Python is a "loop placed inside the body of another loop". 
            This structure is used to handle multidimensional data (like grids or lists within lists), 
            generate patterns, and perform actions that require "multiple layers of iteration".


    -> Branching Structures (Jump Statements)

        -> Used within loops, these statements also control the flow of execution

            -> allowing you to exit a loop early (break) 
            
            -> skip the current iteration (continue)

                -> break: Helps exit a loop early (break)  

                -> continue: Helps Skip The Current Iteration

                -> pass: Acts a place holder

        -> Accessing Strings 

            -> Indexing 

                -> String indexing in Python allows access to 
                "individual characters within a string" 
                using their "position", known as the "index".

                -> Python uses zero-based indexing, meaning the first character is at index 0, 
                the second at index 1, and so on.

                -> Syntax 

                    print(string[index])

                -> Positive Indexing

                    Starts from the beginning of the string.
                    The index of the first character is 0.


                -> Negative Indexing

                    Starts from the end of the string.
                    The index of the last character is -1.
                

                0   1 2  3  4  5
                p   y t  h  o  n
                -6 -5 -4 -3 -2 -1  

                -> NOTE: If Index Is Out Of Range, We Get IndexError   


            -> Slicing 

                -> String slicing in Python is a method for "extracting a portion" 
                (substring) from a larger string.

                -> It utilizes the slice operator [] with specific 
                indices to define the desired segment.

                -> Syntax 

                    string[start:end:step]

                        -> start default is 0 (included) (inclusive)
                        -> stop at this value (excluded) (exclusive)
                        -> step is increment (default step is 1)

                
            -> Earlier We Used range()
                
                range(start, stop, step)
                -> start default is 0 (included) (inclusive)
                -> stop at this value (excluded) (exclusive)
                -> step is increment (default step is 1)

    -> Functions Continued 

        -> Python functions can be defined to accept "parameters" 
        which can act as placeholders for values that will be 
        passed into function when called. 
        
            -> Values passed to the function we call them as "arguments"

            -> We use parameters to make functions dynamic in nature


    -> Based On Arguments Passed To Functions, We Got Five Types 

        -> Positional Arguments

        -> Keyword Arguments

        -> Default Arguments

        -> Arbitrary Positional Arguments

        -> Arbitrary Keyword Arguments


    -> Positional Arguments

        -> In Python, positional arguments are values passed to a function during 
        its call, where the assignment of these values to the function's parameters 
        is determined solely by their "order" (position) in the argument list.

        -> The first argument in the function call is assigned to the first parameter 
        in the function definition, the second to the second, and so on.  

        -> Order Matters: If the order is incorrect, the function will receive the wrong values 
        for its intended parameters, potentially leading to errors or unexpected behavior.


    -> Keyword Arguments

        -> In Python, keyword arguments are a way to pass values to a function by explicitly 
        "naming the parameters" they correspond to, rather than relying on their position 
        in the argument list. 

        -> This offers advantages, primarily in terms of code readability and flexibility.
        

    -> Default Arguments

        -> In Python, default arguments allow you to define a function parameter 
        with a "pre-assigned" value i.e default value 

        -> If a caller does not provide an argument for that parameter during a function call, 
        the default value is automatically used. 
        If an argument is provided, it overrides the default.

        -> Placement Requirement: Default arguments must always be placed after 
        any non-default arguments in the function definition. 
        Attempting to place a non-default argument after a 
        default argument will result in a SyntaxError.

    
    -> Arbitrary Positional Arguments

        -> Arbitrary Means Random or Unknown 

        -> In Python, arbitrary keyword arguments allows a function 
        to accept a unknown number of Positional arguments. 
        This is achieved by placing an asterisk (*) 
        before a parameter name in the function definition.

        -> This parameters will then collect all the positional arguments 
        passed to the function into a tuple.

    -> Scopes In Functions 

        -> Scope: Inside the function code blocks, where you can access data / variable depends on Scope

            -> Local Scope 

            -> Global Scope 

        -> Local Scope 

            -> A local variable declared "inside the function" 

            -> It's lifetime exists only within the function

            -> We cannot use them outside the function  

            -> NOTE: Parameters we pass to the functions, are also local variables 

        
        -> Global Scope 

            -> A global variable declared "outside the function" 

            -> It's lifetime exists within the function, as well as outside the function 

            -> As global variables can be accessed inside the functions, there can be
            name conflicts, in this scenario the preference is given to local variables

                -> NOTE: To Access Global Variable in above scenario, use globals()

            -> If you want global variables to be changed inside the function, we cannot 
            do that directly 

                -> NOTE: To Change global variable inside the function, use global keyword

    -> Lambda Functions 

        -> A Lambda Function in Python is a Small Anonymous Function(Nameless)
        which is defined using "lambda" keyword 

        -> Unlike Standard Functions(block of code), 
        Lambda functions are restricted to single line expression 

        -> Unlike Standard Functions, Lambda functions automatically returned(Implicit) 
        without using a return statement

        -> Lambda Functions are often used for "short, one-time operations" 
        where a full function definition would be unnecessarily verbose.

        -> Using lambda we can write "one liner functions" called "IILE" 
        Immediately Invoked Lambda Expression

        -> Syntax 

            lambda arguments:expression 

        -> NOTE: Generally Lambda Functions Will Be Attached With Higher Order Functions

            -> NOTE: filter() function provides a Concise Way To Perform

            -> It is a powerful tool for "selectively extracting data" based on a "given condition"

            -> Syntax 

                filter(function,iterable)

            -> NOTE: Just Like Using For Loops and Conditionals With Standard Functions 

            -> NOTE: Used Widely In Data Extractions
