    -> Python Syntax / Rules / Best Practices 

        -> Any Python File We Write, it should have extension as .py 

            -> app.py or demo.py 

        -> Python Ignores Lines That Start With # 

            -> # Means Comment 

        -> In Python We Have Functions, which does some Task 

            -> Any Function Has Name i.e function_name()

            -> NOTE: We Have print() - Prints Values On Standard Output 

        -> When Working With Numeric Values (1,5,1.5 etc)
        we can directly use print()

        -> When Working With Text Data, In Python We Call Them as Strings 

            -> Rule / Syntax: Strings Should Be Enclosed in ' ' or " " 


    
    -> Identifiers 

        -> An Identifier is a "Name" used to Uniquely Identify a piece of data in code

            -> Variables 

            -> Functions 

            -> Classes 

            -> Objects 

            -> Methods

            -> etc 

        
        -> Identifier Rules

            -> Can Contain 

                -> Alphabets (a-z A-Z)
                -> Digits (0-9)
                -> Special Symbols (Only _ (underscore) is allowed)

            -> Must Start With 

                -> An Alphabet or _ (underscore)

            -> NOTE: Always Use Proper Way Of Naming Identifiers 

            -> NOTE: Always Use UPPER CASE Naming for Static Data (Fixed Data)


    
    -> Variables         

        -> Variable is a named storage location in computers memory
        thats holds some value or data.

        -> Syntax 

            -> variable_name = value 

                -> variable_name should follow Identifier Rules 

                -> = is called Assignment Operator 
            
                -> value is the data you want to store 

                    -> data = 10 (valid) 
                    -> data = ten (invalid) 
                    -> data = "ten" (valid) 
                    -> @data = "10" (invalid)

            
            -> Variables Allows You To 

                -> Assign Data (Store Data)

                -> Retrieve Data (Get Data)

                -> Manipulate Data (Change Data)


        -> Combine Variables With Custom Statements 

            -> Concatenation: Joining Strings Using + Operator 

            -> NOTE: When Combining Strings With Other Data Types 
            Like int, float, boolean etc use , Operator

        -> Compound Assignment Operators 

            -> Assignment Operator i.e = 
            Used for assigning a value to Variable 

            -> Compound Assignment Operators Combines Arithmetic Operators With Assignment Operator

            -> Used For Short Hand Code (Concise Code)

                -> x = 10
                -> x = x * 10 (long form)

                -> x *= 10 (short form)

                -> NOTE: x = x * 10 and x *= 10, both does same operation 

            -> NOTE: In Other Programming Languages Like (Java), We Have 
            Increment and Decrement Operators 

                -> Increment Operator ++ 
                
                -> Decrement Operator -- 

                -> NOTE: In Python We Don't Have Increment and Decrement Operators,
                instead we use Compound Assignment Operators 

                -> NOTE: We Use Them In Loops 

        
        -> Comparison Operators 

            -> Comparison Operators are used for Comparing Values
            and result will be in boolean type (True/False)

            -> NOTE: We Use Them In Conditions / Conditional Statements
