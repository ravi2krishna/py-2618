    -> Looping Structures (Iteration Statements) - Repetition

        -> Loops in Python are used to "repeatedly" execute a block of code 
        until a specific condition is met or for each item in a sequence.

        -> Repeatedly execute a block of code until a specific condition is met

            -> Every Month Last 3 Days Send SMS / Email to customer about EMI till Loan is Repaid  

        -> Repeatedly execute a block of code for each item in a sequence

            -> Products Catalog With 15k Products (Ecommerce Platform)

        -> NOTE: When you want to do a task multiple times, use loops 

        -> while loop 

            -> while loops execute a block of code repeatedly 
            as long as a specified condition remains True

            -> Syntax 

                while condition:
                    block of code 

            
            -> NOTE: We use while loop, when we don't know number of
            Iterations/Repetitions in advance


        -> for loop 

            -> for loop is used to "iterate over a sequence" 
            (like a list, tuple, string, or range) 

            -> NOTE: For loop executes a block of code once, for each item in the sequence. 

            -> Syntax 

                for variable_name in sequence:
                    block of code 

            -> NOTE: We use for loop, when we know number of
            Iterations/Repetitions in advance

        
        -> range() function

            -> The range() function in Python generates a sequence of numbers. 
            It is commonly used for iterating a specific number of times in for loops.

            range(start, stop, step)
                -> start default is 0 (included) (inclusive)
                -> stop at this value (excluded) (exclusive)
                -> step is increment (default step is 1)

    
        -> Nested Loops 

            -> Loops Inside Loops 
            
            -> A nested loop in Python is a "loop placed inside the body of another loop". 
            This structure is used to handle multidimensional data (like grids or lists within lists), 
            generate patterns, and perform actions that require "multiple layers of iteration".


    -> Branching Structures (Jump Statements)

        -> Used within loops, these statements also control the flow of execution

            -> allowing you to exit a loop early (break) 
            
            -> skip the current iteration (continue)

                -> break: Helps exit a loop early (break)  

                -> continue: Helps Skip The Current Iteration

                -> pass: Acts a place holder

        -> Accessing Strings 

            -> Indexing 

                -> String indexing in Python allows access to 
                "individual characters within a string" 
                using their "position", known as the "index".

                -> Python uses zero-based indexing, meaning the first character is at index 0, 
                the second at index 1, and so on.

                -> Syntax 

                    print(string[index])

                -> Positive Indexing

                    Starts from the beginning of the string.
                    The index of the first character is 0.


                -> Negative Indexing

                    Starts from the end of the string.
                    The index of the last character is -1.
                

                0   1 2  3  4  5
                p   y t  h  o  n
                -6 -5 -4 -3 -2 -1  

                -> NOTE: If Index Is Out Of Range, We Get IndexError   


            -> Slicing 

                -> String slicing in Python is a method for "extracting a portion" 
                (substring) from a larger string.

                -> It utilizes the slice operator [] with specific 
                indices to define the desired segment.

                -> Syntax 

                    string[start:end:step]

                        -> start default is 0 (included) (inclusive)
                        -> stop at this value (excluded) (exclusive)
                        -> step is increment (default step is 1)

                
            -> Earlier We Used range()
                
                range(start, stop, step)
                -> start default is 0 (included) (inclusive)
                -> stop at this value (excluded) (exclusive)
                -> step is increment (default step is 1)

    -> Positional Arguments

        -> In Python, positional arguments are values passed to a function during 
        its call, where the assignment of these values to the function's parameters 
        is determined solely by their "order" (position) in the argument list.

        -> The first argument in the function call is assigned to the first parameter 
        in the function definition, the second to the second, and so on.  

        -> Order Matters: If the order is incorrect, the function will receive the wrong values 
        for its intended parameters, potentially leading to errors or unexpected behavior.


    -> Keyword Arguments

        -> In Python, keyword arguments are a way to pass values to a function by explicitly 
        "naming the parameters" they correspond to, rather than relying on their position 
        in the argument list. 

        -> This offers advantages, primarily in terms of code readability and flexibility.
        

    -> Default Arguments

        -> In Python, default arguments allow you to define a function parameter 
        with a "pre-assigned" value i.e default value 

        -> If a caller does not provide an argument for that parameter during a function call, 
        the default value is automatically used. 
        If an argument is provided, it overrides the default.

        -> Placement Requirement: Default arguments must always be placed after 
        any non-default arguments in the function definition. 
        Attempting to place a non-default argument after a 
        default argument will result in a SyntaxError.

    
    -> Arbitrary Positional Arguments

        -> Arbitrary Means Random or Unknown 

        -> In Python, arbitrary keyword arguments allows a function 
        to accept a unknown number of Positional arguments. 
        This is achieved by placing an asterisk (*) 
        before a parameter name in the function definition.

        -> This parameters will then collect all the positional arguments 
        passed to the function into a tuple.

        first parameter, which refers to Instance of object being created

        -> __init__() can Additionally take other parameters to receive values 
        for initializing objects attributes 

        -> Syntax

            class ClassName:
                def __init__(self, parameter1, parameter2, ...):
                    self.parameter1 = parameter1
                    self.parameter2 = parameter2

    

    -> Instance Members (Associated With Objects)

        -> Instance Variables  

            -> Instance Variables belongs to an "object" i.e instance, not the class 

            -> Instance Variables are defined in the __init__ method using "self" keyword 

            -> Each Object you create has it's own copy of instance variable with different values 

            -> Instance Variables are accessed via self.variable_name

            -> Syntax

                class Demo:
                    def __init__(self,parameter):
                        self.instance_var = value 

        
        -> Instance Methods 

            -> Methods which are defined inside a class which 
            operates on instance variables 

            -> Instance Methods are "very commonly used" types of methods in OOP 

            -> Instance Methods always take "self" as the first parameter 

            -> Instance Methods can access instance variables and also class variables too 

            -> Called using object_name.method()



    -> Class Members (Associated With Class)

        -> Class Variables 

            -> Class Variables are "shared across all the instances of class" 
            i.e "shared by all the objects" of the class 

            -> Class Variables belong to class, rather than objects, 
            ideal for storing data that is common/fixed for all objects 

            -> Defined inside the class, but outside the methods 

            -> Accessed using Classname.variable_name or object.variable_name 

                -> Recommended is using Classname.variable_name

            -> NOTE: Class Variables are "memory efficient" as 
            only one copy is there unlike multiple copies like objects 

            -> Syntax

                class Demo:
                    class_var = "i'm shared data"


        -> Class Methods

            -> Methods which are defined inside a class which 
            operates on class variables 

            -> Class Methods are not "very commonly used" types of methods in OOP 

            -> Class Methods always take "cls" as the first parameter 

            -> Class Methods are defined using @classmethod decorator 

            -> Class Methods can access class variables, 

                -> NOTE: Accessing instance data inside a class method gives error 

            -> Called using ClassName.method()

    

    -> Static Members (Not Associated With Classes & Objects)

        -> NOTE: In python we don't have Static Variables 

            -> In other languages like java static variable is equivalent to Class Variable 

            -> Static Variable In Other Languages == Class Variable In Python

        -> Static Methods 

            -> Static Methods are not bound to either class or object 

            -> Static Methods does not depend on instance variable or class variable 

            -> Not a commonly used method 

            -> These Methods Don't take self or cls as first parameter 

            -> NOTE: Behaves like a normal function, but inside a class  

            -> Declared used @staticmethod decorator 

            -> Used as utilities / helper functions 

            -> Called Using ClassName

    -> Inheritance

        -> Inheritance is a core OOP concept where a new class, 
        called a subclass or child class, acquires the 
        Properties(Variables) and Behaviors(Methods) from an 
        existing class, called as Super Class or Parent Class.

        -> NOTE: Main purpose of Inheritance is CODE Reusability.

        -> Syntax 

            class Parent:
                pass 

            class Child(Parent):
                pass 

    
    -> Types Of Inheritance

        -> Single Level Inheritance

            -> One Parent -> One Child 

        -> Multi Level Inheritance

            -> GrandParent -> Parent -> Child 

        -> Multiple Inheritance

            -> One Child -> Multiple Parents 

        -> Hierarchical Inheritance

            -> One Parent -> Multiple Child 

        -> Hybrid Inheritance

            -> Combination Of Types Of Inheritance


    
    -> Encapsulation

        -> Encapsulation is a core concept in object-oriented programming (OOP) that "binds"
        Properties(Variables) and Behaviors(Methods) into a single unit called "Class".

        -> NOTE: Binding Of Properties(Variables) and Behaviors(Methods) is done in Classes 

            -> https://www.cincom.com/wp-content/uploads/2025/08/ENCAPSULATION-01.webp

        
        -> Encapsulation process also involves "restricting" direct access to an 
        object's internal state, which is a principle known as "data hiding" 

        -> Other Languages like Java or C++ "enforces" Strict Rules for Encapsulation,  
        coming to python there is no Strict enforcing. 

            -> Java/C++ = “You’re not allowed” 

            -> Python = “You shouldn’t, but you can if you insist”


        -> NOTE: Python intentionally does not enforce strict runtime access modifiers 
        like Java or C++ do. It relies instead on naming conventions and a 
        community philosophy famously summarized by Python's creator, Guido van Rossum, 
        as "we are all consenting adults here". 
        
        -> This means Python assumes developers are responsible enough to 
        respect visibility indicators rather than forcing the interpreter to 
        build rigid walls around code.

        -> While Python does not have strict access modifiers like "public", "private" or "protected" 
        keywords found in some other languages(java, c++), 


        -> Hiding Data 

            -> We have public access 

                -> Without any special naming conventions or prefixes 
                are considered as public and can be accessed from anywhere 

            
            -> We have private access 

                -> prefixed with a double underscore (__)

                -> cannot be accessed from outside 

            
            -> We have protected access 

                -> prefixed with a single underscore (_)

                -> cannot be accessed from outside, but can be accessed in sub classes
